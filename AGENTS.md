# AGENTS.md — Brasaland

## Project Context

This repository contains the Brasaland company project.
All development must follow the official BRIEFING.md
and the existing monorepo structure.

## Required Reading

At the beginning of every session, read:

- BRIEFING.md
- memory-bank/projectbrief.md
- memory-bank/techContext.md
- memory-bank/progress.md
- .agents/rules/monorepo-structure.md

## Mandatory Development Workflow

Before committing any changes:

1. Read the required project context files.
2. Review the relevant folder README files.
3. Plan the changes according to the requirements.
4. Implement changes in the correct folders.
5. Test and review the changes.
6. Update the memory bank with progress and decisions.
7. Review the final changes before committing.

## Protected Files and Folders

Do not modify the following without developer approval:

- BRIEFING.md
- AGENTS.md
- .devcontainer/
- .gitignore
- infra/
- Existing applications unrelated to the current task.

## Development Rules

- Follow the existing monorepo structure.
- Do not create duplicate application folders.
- Keep solutions simple and maintainable.
- Do not invent business requirements.
- Ask the developer when requirements are unclear.
- Use .agents/rules/ for coding assistant rules.
- Use .agents/skills/ for reusable coding assistant skills.
